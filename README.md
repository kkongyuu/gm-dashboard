# 📊 GM Management & Branch Analytics Dashboard

ระบบเว็บแดชบอร์ด (Web Dashboard) บริหารจัดการและติดตามผลการดำเนินงานของผู้จัดการสาขา (GM Monitor), ประสิทธิภาพธุรกิจ (KPI), รายการปัญหาคงค้าง (Problem List) และรายงานการเบิกจ่ายทางบัญชี (Accounting Report)

แปลงจากระบบ **Google Apps Script LINE Bot** เดิม ให้เป็น **Dashboard Website** ที่ใช้งานง่าย สวยงาม แสดงผลทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## 🌟 ฟีเจอร์หลักของระบบ (Key Features)

### 1. 📊 ภาพรวม GM Monitor (Executive Overview)
* **Weekly Meeting Compliance**: ติดตามสถิติการประชุมรายสัปดาห์ของผู้จัดการทั้ง 12 คน (เป้าหมาย 8 ครั้ง/คน) แสดงอัตราความสำเร็จ (% Compliance) และสถานะ 🟢/🔴
* **Revenue Target & Business Health**: สรุปสัดส่วนผลประกอบการว่าสาขาใดผ่านเกณฑ์ (🟢), เสี่ยงต่ำกว่าเป้า (🟡), หรือไม่เป็นไปตามเป้า (🔴)
* **Problem / Incident Tally**: แจ้งเตือนจำนวนปัญหาคงค้างแยกตามระดับความวิกฤต (🔴 Critical, 🟡 High, 🟣 Overdue)
* **Manager Performance Matrix**: ตารางเปรียบเทียบผลงานของผู้จัดการแต่ละคน พร้อมปุ่มดูประวัติและสาขาในการดูแล

### 2. 🏢 ผลประกอบการสาขา (Branch KPI Monitor)
* แสดงการ์ดผลงานของแต่ละสาขาแบบ Real-time
* ตรวจสอบยอดจริงเทียบเกณฑ์: **Target Revenue**, **NRM** (New Case Management), **CRM** (Customer Relationship)
* ระบบตัวกรองอัจฉริยะ: กรองตามผู้จัดการ, กรองตามสถานะเป้าหมาย (🟢/🟡/🔴), และค้นหาตามชื่อสาขา

### 3. ⚠️ ติดตามปัญหาคงค้าง (Problem & Incident Tracker)
* รวบรวมปัญหาที่ยังไม่ปิด (`status !== 'ปิดแล้ว'`) จากทุกชีทของผู้จัดการ
* ไฮไลต์เคสพิเศษ: ปุ่มคัดกรองเฉพาะเคสที่ **"ต้องการ GM ช่วยเหลือ"** 🚨
* ค้นหาและคัดกรองตามความเร่งด่วน: Critical, High, Overdue

### 4. 💰 รายงานการเบิกจ่ายบัญชี (Accounting & Withdrawals)
* **ยอดเบิกจ่ายรวมเดือนนี้**: คำนวณจากชีท `Dashboard This month`
* **กราฟแนวโน้มรายวัน (Daily Trend)**: ติดตามการไหลเวียนของการเบิกเงินในแต่ละวัน
* **จัดอันดับสาขาที่เบิกสูงสุด**: ดูกราฟแท่งเปรียบเทียบสาขาที่มีการเบิกเงินมากที่สุด
* **ตารางแจกแจงรายการ**: ค้นหารายการเบิกและดูรายละเอียดได้ทันที

### 5. ⚙️ ระบบเชื่อมต่อข้อมูลสด & ส่งออก (Live Data & Export)
* **100% Live Google Sheets Mode**: ดึงข้อมูลจริงสดจาก Google Sheets ผ่าน Google Apps Script Web App API เท่านั้น (ไม่มีการใช้ข้อมูลจำลอง/Mockup)
* **Period Switcher**: สลับรอบการประเมินได้ตลอดเวลา (รอบ 1-10, 11-20, 21-31)
* **Export CSV**: ส่งออกข้อมูลสรุปเป็นไฟล์ Excel/CSV ได้ด้วยคลิกเดียว

## 🚀 วิธีการนำไปใช้งาน (Deployment Guide)

มี 2 วิธีหลักในการใช้งาน ขึ้นอยู่กับความสะดวกของทีมงาน:

### วิธีที่ 1: ติดตั้งบน Google Apps Script โดยตรง (แนะนำ - ฟรี 100% ไม่มีค่าเซิร์ฟเวอร์)
วิธีนี้จะทำให้ Dashboard รันอยู่บน Cloud ของ Google ตลอด 24 ชม. และสามารถส่งลิงก์ให้ทีมงานเปิดผ่านเบราว์เซอร์ได้ทันที

1. เปิดไปที่โปรเจกต์ **Google Apps Script** เดิมของท่านที่เชื่อมกับ Google Sheets
2. คัดลอกโค้ดจากไฟล์ `Code.gs` ไปวางแทนที่ (หรืออัปเดต) โค้ดเดิม
   * *หมายเหตุ: โค้ดนี้ยังคงมีฟังก์ชัน `doPost(e)` สำหรับ LINE Bot เดิมอยู่ ทำให้บอททำงานได้ตามปกติเหมือนเดิมทุกประการ*
3. ในแถบเมนูด้านซ้ายของ Google Apps Script กดเครื่องหมาย **`+` (เพิ่มไฟล์)** > เลือก **HTML** > ตั้งชื่อไฟล์ว่า `index`
4. คัดลอกโค้ดทั้งหมดจากไฟล์ `index.html` ไปวางในไฟล์ `index.html` บน Google Apps Script
5. กดปุ่มสีน้ำเงินมุมขวาบน **Deploy (ทำให้ใช้งานได้)** > เลือก **New deployment (การทำให้ใช้งานได้รายการใหม่)**
6. ตั้งค่าดังนี้:
   * **Select type**: Web app (เว็บแอป)
   * **Description**: `GM Dashboard v1`
   * **Execute as**: `Me (อีเมลของคุณ)`
   * **Who has access**: `Anyone (ทุกคน)`
7. กด **Deploy** และอนุมัติสิทธิ์ (Authorize access)
8. คัดลอก **Web app URL** ที่ได้ (เช่น `https://script.google.com/macros/s/.../exec`) นำไปเปิดในเว็บเบราว์เซอร์เพื่อใช้งานได้ทันที!

---

### วิธีที่ 2: รันบนเครื่องคอมพิวเตอร์ Local (ผ่าน Python)

หากต้องการเปิดใช้งานบนคอมพิวเตอร์ของคุณเองเพื่อทดสอบหรือปรับแต่งดีไซน์:

1. ดับเบิลคลิกที่ไฟล์ **`start_dashboard.bat`** (หรือพิมพ์คำสั่ง `python server.py` ใน Terminal)
2. เบราว์เซอร์จะเปิดหน้าเว็บ `http://localhost:8080` ขึ้นมาให้อัตโนมัติ
3. หากต้องการต่อกับข้อมูลจริงจาก Google Sheets:
   * กดปุ่มรูปฟันเฟือง **⚙️ (การตั้งค่า)** มุมขวาบน
   * เลือกโหมด **"🌐 Google Sheet API (Live)"**
   * วาง Google Apps Script Web App URL ของคุณ
   * กด **"บันทึกการตั้งค่า"**
